# Trivia Quiz

Interactive 10-question trivia quiz with a per-question countdown timer and live scoring. Pure vanilla JS, no dependencies.

## Live Demo

https://srausahowl.github.io/quiz-app/

## Usage

Open `index.html` in any modern browser. Zero dependencies, zero build step.

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Tech

- Vanilla HTML / CSS / JavaScript
- No frameworks, no build tools
